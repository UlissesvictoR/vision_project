# 📸 Face Detection Prototype (MLKit + GetX)

Protótipo funcional de **detecção facial em tempo real**:
- [**Camera**](https://pub.dev/packages/camera) para capturar o vídeo ao vivo;
- [**Google MLKit Face Detection**](https://pub.dev/packages/google_mlkit_face_detection) para reconhecer rostos e detectar movimento;
- [**GetX**](https://pub.dev/packages/get) para gerenciamento de estado e navegação;
- Arquitetura **MVVM** para melhor organização e escalabilidade.

---

## 🚀 Funcionalidades

- Detecção facial em tempo real  
- Desenho de contorno sobre o rosto (com ajuste de rotação/espelhamento no Android)  
- Captura automática quando o rosto permanece imóvel por 1 segundo  
- Preview da foto com opção de confirmar ou refazer  
- Arquitetura MVVM + GetX para fácil manutenção
